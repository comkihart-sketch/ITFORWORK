# ShiftFlow • ระบบจัดตารางเวรและสลับกะการทำงานแผนก

เว็บแอปพลิเคชันสำหรับจัดตารางเวรและบริหารจัดการกะการทำงานของพนักงานในแผนก รองรับการลงเวลาทำงานด้วยตนเอง การขอสลับเวรแบบอนุมัติสองฝ่าย (Peer-to-Peer Swap) ปฏิทินตารางเวรรวม และระบบบันทึกประจำวันแยกสิทธิ์สาธารณะ/ส่วนตัว

---

## 🚀 วิธีการเปิดใช้งานระบบ (Quick Start)

### 1. การเปิดรันระบบแบบรวดเร็ว
เปิด Terminal หรือ PowerShell ที่โฟลเดอร์นี้ แล้วพิมพ์:
```bash
npm start
```
ระบบจะเริ่มทำงานทันทีที่: **`http://localhost:5000`**

### 2. บัญชีผู้ดูแลระบบเริ่มต้นสำหรับเริ่มใช้งาน (Default Administrator)

ระบบถูกล้างข้อมูลทดสอบทั้งหมดเรียบร้อยแล้ว และสร้างบัญชี Administrator เริ่มต้นไว้สำหรับให้หัวหน้างาน/ผู้ดูแลระบบเข้าใช้งาน:

| ข้อมูลเข้าสู่ระบบ | ค่าเริ่มต้น |
|---|---|
| **Username** | `admin` |
| **Password** | `1234` |
| **สิทธิ์ (Role)** | **Administrator** (ผู้ดูแลระบบ) |

> 📌 **ขั้นตอนการเริ่มใช้งานจริง:**
> 1. เข้าสู่ระบบด้วย `admin` / `1234`
> 2. ไปที่เมนู **"4. เมนูตั้งค่า (Admin Settings) -> 3. รายชื่อบุคลากร"** เพื่อเพิ่มรายชื่อและ Username/Password ของพนักงานในแผนก
> 3. สามารถเปลี่ยนรหัสผ่านของบัญชีแอดมินให้ปลอดภัยยิ่งขึ้นได้ทันที
> 4. ปรับแต่งประเภทกะเวรหรือวันหยุดนักขัตฤกษ์ของแผนกได้ตามต้องการ
> 5. ให้พนักงานในแผนกเข้าสู่ระบบด้วย Username/Password ของแต่ละท่าน เพื่อลงเวรในปฏิทินและใช้งานระบบได้ทันที!

## ✨ 4 หน้าจอหลักและฟังก์ชันการใช้งาน

### 1. ปฏิทินเวรรวม (Master Roster Calendar)
- แสดงตารางเวรของทุกคนในแผนกในรูปแบบ Matrix (แถวคือรายชื่อพนักงาน, คอลัมน์คือวันที่ของเดือน)
- ป้ายสีกำกับเวรชัดเจน (เช่น เวรเช้า, เวรบ่าย, เวรดึก, วันหยุด)
- ไฮไลต์วันหยุดนักขัตฤกษ์และวันหยุดพิเศษประจำแผนกด้วยสีแดงอ่อน
- **ตราประทับการสลับเวร**: แสดงไอคอน `🔄 สลับกับ [ชื่อเพื่อน]` ในช่องเวรที่มีการสลับ เพื่อความโปร่งใส
- แถบ **บันทึกสาธารณะประจำวัน** ด้านล่างของตาราง

### 2. ลงเวร & สลับเวร (My Shifts & Swap Center)
- **ลงเวลา/แก้ไขเวรของตนเอง**: เลือกวันที่และกะที่ต้องการลงเวลา
- **ระบบขอสลับเวร (Shift Swap Workflow)**:
  1. เลือกวันที่ และเลือกเพื่อนร่วมงานที่ต้องการสลับกะด้วย
  2. ระบุเหตุผล และกดยืนยันส่งคำขอ
  3. ระบบจะยังไม่สลับเวรจนกว่าเพื่อนร่วมงานจะกดยินยอม
  4. เมื่อเพื่อนร่วมงานเข้ามาที่หน้านี้ จะพบการ์ดแจ้งเตือน **"รอคุณอนุมัติ"** พร้อมปุ่ม **"✓ อนุมัติการสลับเวร"** และ **"✕ ปฏิเสธ"**
  5. เมื่อกดยืนยันอนุมัติ ระบบจะสลับเวรทั้งสองฝ่ายในฐานข้อมูลทันที และติดตราประทับในตารางเวรรวม

### 3. บันทึกประจำวัน (Daily Notes)
- เลือกระบุวันที่ต้องการบันทึก
- **ตัวเลือกระดับความเป็นส่วนตัว (Privacy Toggle)**:
  - 🌐 **ทุกคนเห็น (Public)**: แสดงให้ทุกคนในแผนกเห็น และนำไปแสดงในตารางเวรรวม
  - 🔒 **เห็นคนเดียว (Private)**: จัดเก็บเป็นความลับเฉพาะตัวผู้เขียน ผู้ใช้อื่นไม่สามารถมองเห็นได้
- ฟิลเตอร์คัดกรองดูบันทึก: ทั้งหมด / เฉพาะทุกคนเห็น / เฉพาะส่วนตัว

### 4. เมนูตั้งค่าผู้ดูแลระบบ (Admin Settings)
- **จัดการประเภทเวร (Shift Types)**: กำหนดรหัส, ชื่อเวร, เวลาเริ่ม-สิ้นสุด, รหัสสีพื้นหลังและตัวอักษร, จำนวนคนขั้นต่ำต่อกะ
- **จัดการวันหยุด (Holidays)**: เพิ่ม/ลบวันหยุดนักขัตฤกษ์ และวันหยุดพิเศษของแผนก
- **จัดการบุคลากร (Staff Accounts)**: เพิ่มสมาชิกใหม่, กำหนดสิทธิ์ Admin หรือ Staff, ระบุตำแหน่งและเบอร์โทรศัพท์

## 🛠️ โครงสร้างเทคโนโลยีและซอร์สโค้ด

- **Backend**: Node.js + Express 5 + `node:sqlite` (SQLite ในตัวของ Node.js ปลอดภัย รวดเร็ว ไม่ต้องติดตั้ง binary เพิ่มเติม)
- **Frontend**: React 18 + Vite + Tailwind CSS v4 + Lucide Icons
- **Authentication**: JWT Token + Bcrypt Password Hashing + Role-Based Access Control
- **Database**: `shifts.db` (SQLite relational schema พร้อม Atomic Transactions สำหรับการสลับเวร)
